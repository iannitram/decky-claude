# Glossary

The project's own words, one line each. `/grill-with-docs` adds to this during the interview; code, issues and specs use these words.

| Term | Means | Not to be confused with |
|---|---|---|
| Session | The one Claude Code process the plugin runs in tmux | A chat conversation or a transcript file |
| Chat view | The message-style view of the session in the panel | The terminal tab |
| Terminal tab | The rendered tmux screen of the same session | A separate shell |
| Launch diagnosis | Reading a game's logs and Proton state to explain why it will not start | Debugging Steam's UI |
